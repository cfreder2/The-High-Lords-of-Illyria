# How we work

How The High Lords of Illyria is made, as of 15 Nov 2026. Written from what the repository and its docs show. Paths are on `master` unless they start with `../`.

Who does what: the owner directs. He plays the builds, sends screenshots, sets the design and makes every decision that matters. The code, the art pipeline runs, the measurements and the reviews are done by AI agents under that direction. This page says so plainly because the rest of the devlog would be misleading without it.
