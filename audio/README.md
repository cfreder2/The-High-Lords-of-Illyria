# Audio

No sound files are kept on this branch. Sound effects have been in the code since 28 Oct 2026. They live with the code on `master`:

- `game/web/sfx/`: the effects and their manifest (90 sounds in 256 files as of 15 Nov 2026). All synthesised by script so far.
- `game/web/voice/`: the soldiers' lines. None of the 1,055 is recorded yet; the game uses placeholders.
- `docs/SOUND_EFFECTS.md`, `docs/VOICE_LINES.md`, `docs/VOICE_CHECKLIST.md`: what plays and when, and the recording script.
- `tools/sound-editor/`: a local page to audition, record and choose sounds.

The builds filmed in `builds/` (27 and 28 Oct) are silent videos.

How sound is worked on: [`../how-we-work/sound.md`](../how-we-work/sound.md).
